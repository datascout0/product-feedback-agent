This document summarizes the current onboarding and support strategy for
internal planning purposes. It is intended to give the analysis agent
grounding context when weighing customer onboarding/support feedback against
stated priorities. It exists to prove the same Product Feedback Agent
architecture generalizes to a second domain -- customer onboarding, support,
and workflow friction -- without any code change.

# Onboarding Strategy

## SSO Rollout Priorities

Self-serve SSO configuration for enterprise accounts is a Q3 priority. Today,
enterprise customers depend on manual back-and-forth with support to get SSO
working, which this priority is meant to remove.

## Onboarding Checklist Redesign

The onboarding checklist is being redesigned so each step has an explicit,
visible completion state, reducing repeated or redundant setup work for
SMB and startup accounts.

## Support Ticket Quality

Reducing reopened support tickets is a tracked support-quality metric this
quarter, particularly for tickets related to account setup and SSO.
